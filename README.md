# 🩺 The Gradient Glider: Hearthstone Health Monitor

An interactive Machine Learning simulation designed to teach **Linear Regression** and optimization via **Gradient Descent** from scratch. You play as a Healthcare Data Scientist at a major hospital network, calibrating an early-warning telemetry algorithm to predict patient Blood Pressure based on raw Heart Rate inputs[span_0](start_span)[span_0](end_span).

## 🎓 Learning Objectives

This project focuses on teaching:
* **Continuous Regression Analysis:** Mapping numerical input variables to a continuous scale of real numbers rather than rigid sorting bins[span_1](start_span)[span_1](end_span).
* **Gradient Descent:** The optimization algorithm that mathematically navigates parameters along the steepest negative slope of a loss curve[span_2](start_span)[span_2](end_span).
* **Mean Squared Error (MSE) Loss:** Evaluating model accuracy by squaring individual error points to heavily penalize extreme predictive failures[span_3](start_span)[span_3](end_span).
* **Learning Rates and Epochs:** Understanding how incremental adjustments per full data iteration modify parameter convergence[span_4](start_span)[span_4](end_span).

---

## ✨ Features

* **Healthcare Domain Scenario:** Translates core calculus and mathematical parameter updating into a tangible medical diagnostics framework.
* **Pure Mathematical Transparency:** Displays live telemetry logs illustrating the exact loss shrinkage, slope shifts (weights), and intercepts (biases) calculated per epoch[span_5](start_span)[span_5](end_span).
* **Custom Parametric Tuning:** Lets users control optimization length to see firsthand how long an algorithm requires to converge on real parameters.
* **Zero Engine Dependencies:** Written using core Python syntax natively, mapping partial derivatives manually without relying on black-box external frameworks[span_6](start_span)[span_6](end_span).
